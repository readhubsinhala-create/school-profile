SCHOOL PROFILE - PHOTO GALLERY
===============================

සිංහල උපදෙස්

1. මෙම ZIP file එක Extract කරන්න.
2. Extract කළ folder එක ඇතුළේ "photos" folder එක විවෘත කරන්න.
3. පෙන්වීමට අවශ්‍ය සියලුම photos (JPG, JPEG, PNG, WEBP හෝ GIF) එම photos folder එකට copy කරන්න.
4. Photo names වෙනස් කිරීමට හෝ index.html එක edit කිරීමට අවශ්‍ය නැහැ.
5. GitHub repository එකක් සාදා මෙම project folder එකේ ඇතුළත ඇති සියලුම files සහ folders upload කරන්න.
   වැදගත්: index.html file එක repository එකේ root එකේ තිබිය යුතුයි.
   .github folder එකත් අනිවාර්යයෙන් upload කරන්න.
6. Repository එකේ Settings > Pages වෙත යන්න.
7. Build and deployment යටතේ Source = GitHub Actions ලෙස තෝරන්න.
8. Actions tab එකේ workflow එක අවසන් වනතුරු රැඳී සිටින්න. පසුව Settings > Pages හි website link එක ලැබේ.

ඡායාරූප ස්වයංක්‍රීයව හඳුනාගැනීම:
- GitHub එකට upload කරන විට photos folder එකේ ඇති සියලුම supported photos ලැයිස්තුගත වේ.
- පසුව photos එකතු කළහොත් නැවත upload/deploy කළ යුතුයි. ඔබගේ අවශ්‍යතාවයට අනුව මුලින්ම photos සියල්ල එකතු කර පසුව publish කරන්න.
- Photos 50-100ක් සඳහා හැකි නම් දිග පැත්ත 1600-2000px පමණට resize කර JPEG quality 75-85% භාවිතා කරන්න.

ගොනු ව්‍යුහය:
School_Profile_Gallery_Auto/
  index.html
  photos/
    ඔබගේ photos මෙතැනට
  .github/
    workflows/
      pages.yml

සටහන:
- Photo formats: JPG, JPEG, PNG, WEBP, GIF
- Photos folder එකේ subfolders තිබුණත් photos සොයාගනී.
- ළමයින්ගේ හෝ පාසලේ පුද්ගලික ඡායාරූප public කරනවා නම් අදාළ අවසර ලබාගන්න.
